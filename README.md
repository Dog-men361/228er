# LexRF

Нативный Android-справочник российского законодательства, без Gradle и Android Studio. Java, JDK 17, Android SDK, PowerShell. Android 6.0 и новее.

## Возможности

- Поиск по описанию ситуации и номеру статьи; локальный алгоритм сопоставления слов и фраз, не нейросеть.
- 10 разделов, локальные краткие карточки и ссылки на опубликованные редакции законов.
- Тёмная и светлая темы, шесть акцентных цветов, размер текста 80–140%.
- Проверка публичных GitHub Releases; установка APK через системный интерфейс Android.
- Введённые ситуации не отправляются в сеть.

**Ограничения:** локальная подборка не является полным корпусом законов и не установит наличие или отсутствие нарушения. Для актуального текста переходите к источнику. Данные карточек — краткие авторские объяснения, не цитаты. Источники: https://pravo.gov.ru/ и документы в `assets/codes.tsv`. Содержимое нужно проверять при каждом юридически значимом использовании.

## Сборка без IDE

Установите JDK 17, Android SDK Platform 35 (или новее), Build Tools 35 (или новее), PowerShell 7 (или Windows PowerShell 5). Укажите переменные `JAVA_HOME`, `ANDROID_SDK_ROOT`. Создайте свой закрытый ключ Android и задайте `LEXRF_KEYSTORE` (путь к keystore), `LEXRF_KEY_PASSWORD` (пароль), при необходимости `LEXRF_KEY_ALIAS` (по умолчанию `lexrf`). Не публикуйте ключ и пароль.

```powershell
./build.ps1 -Output "$PWD/LexRF.apk"
```

Для обновления уже установленной первой версии обязателен тот же ключ подписи. Не удаляйте его. Имя пакета `ru.dogmen.lexrf` должно остаться неизменным.

## GitHub

1. Создайте репозиторий и загрузите только эти исходные файлы, включая `.github/workflows/release.yml` (без ключа, пароля и APK).
2. В Settings → Secrets and variables → Actions сохраните приватные `LEXRF_KEYSTORE_BASE64` (base64 файла ключа) и `LEXRF_KEY_PASSWORD`.
3. Для новой версии увеличьте `android:versionCode` и измените `android:versionName` в `AndroidManifest.xml`, а также `VERSION` в `MainActivity.java`.
4. Отправьте изменения в `main` (или создайте соответствующий тег, например `v1.0.1`). Workflow соберёт подписанный APK и опубликует новую версию, если релиз ещё не существует. Проверяйте сборку перед публикацией.
5. В LexRF репозиторий `Dog-men361/228er` указан по умолчанию. В настройках нажмите «Проверить обновления». Скачайте APK из релиза и подтвердите установку.

Дистанционная публикация APK возможна; скрытая/беззвучная установка на обычный Android без специальных полномочий невозможна.
